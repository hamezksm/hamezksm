## About Me

I'm a software engineer based in Nairobi, working across backend, mobile, and DevOps. I studied Computer Science at Kenyatta University and went through ALX's Software Engineering program in 2023.

Right now I split my time across a few things I'm building — CropCare AI (computer vision for crop disease detection), Beba (a cargo transportation marketplace), and Suluhu OnDemand, where I work as a Full Stack Engineer and IT admin owning cloud infrastructure end to end: provisioning, security hardening, backups, incident response.

Before that I built a blockchain-based payments app at SmartPay Network, and at Seven Skies I built a data collection and analysis system used by a government org to track food security across health, agriculture, livestock, water, and education. I've also done full-stack consulting (Codefremics, Solutech) and freelanced since 2022 — backend systems, AWS deployments, mobile apps for clients.

Stack: Python, Go, TypeScript, Dart, Kotlin — Django/Flask/Gin for APIs, Flutter/React/Next.js/Jetpack Compose on the front end, AWS for infra.

Placed 4th at the 637 Capital Hackathon, and built an AI-driven helpdesk at the Davis & Shirtliff hackathon that reused documented fixes to cut recurring support tickets.
